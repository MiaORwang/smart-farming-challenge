# smart-farming-challenge
Bilingual interactive educational games for science communication in livestock farming.

**Interactive Educational Demo
Basis / Base version:** v6 — Mobile Optimized

### Deutsch

**Über die Anwendung**
Smart Farming Challenge ist eine zweisprachige Sammlung interaktiver Lernspiele zur Wissenschaftskommunikation in der Nutztierhaltung. Die bereitgestellte Version umfasst drei Themenbereiche:

* **Necktag© Detective** — Milchkuh
* **Moor Guardian** — Wasserbüffel
* **Hen Welfare Inspector** — Legehenne

Die interaktiven Aufgaben dienen der anschaulichen Vermittlung ausgewählter Fragestellungen und sind keine validierten Diagnose- oder Überwachungssysteme.

**Start**

1. `index.html` in einem aktuellen Browser öffnen.
2. Sprache (Deutsch/Englisch) auswählen.
3. Eines der drei Spiele starten und den Anweisungen auf dem Bildschirm folgen.

**Technik**

* HTML, CSS und JavaScript; keine Datenbank erforderlich.
* Die vorliegende Fassung ist als eigenständige HTML-Datei ausgelegt.
* Bei Veröffentlichung über die Universität müssen Hosting, Logos und weitere enthaltene Materialien freigegeben sein.

**Wissenschaftlicher Hinweis**
Die Inhalte sind für die interaktive Demonstration vereinfacht. Spielentscheidungen oder -ergebnisse dürfen nicht als reale Tierwohlbewertung, Gesundheitsdiagnose oder validierte Sensorauswertung interpretiert werden.

**Entwicklungsstand**
Interactive Educational Demo: eine Demonstrationsfassung für Lehre, Messe und Wissenschaftskommunikation; keine Zusicherung einer vollständigen technischen, sicherheitsbezogenen oder barrierefreiheitsbezogenen Prüfung.

### English

**About**
Smart Farming Challenge is a bilingual collection of interactive educational games for science communication in livestock farming. This release includes three topics:

* **Necktag© Detective** — dairy cattle
* **Moor Guardian** — water buffaloes
* **Hen Welfare Inspector** — laying hens

The activities illustrate selected research-related questions. They are not validated diagnostic or monitoring systems.

**Getting started**

1. Open `index.html` in a current web browser.
2. Select German or English.
3. Choose one of the three games and follow the on-screen instructions.

**Technical notes**

* HTML, CSS and JavaScript; no database required.
* This release is designed as a standalone HTML file.
* University publication requires appropriate approval for hosting, logos and any other included materials.

**Scientific disclaimer**
The content is simplified for interactive demonstration. In-game decisions and results must not be treated as actual animal welfare assessments, health diagnoses or validated sensor analyses.

**Release status**
Interactive Educational Demo: a demonstration release for teaching, exhibitions and science communication. It does not imply completion of comprehensive technical, security or accessibility audits.
