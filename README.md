## Deutsch

### Über die Anwendung

Smart Farming Challenge ist eine zweisprachige Sammlung interaktiver Lernspiele zur Wissenschaftskommunikation in der Nutztierhaltung.

Die bereitgestellte Version umfasst drei Themenbereiche:

- **Necktag© Detective** — Milchkuh
- **Moor Guardian** — Wasserbüffel
- **Hen Welfare Inspector** — Legehenne

Die interaktiven Aufgaben dienen der anschaulichen Vermittlung ausgewählter Forschungsfragen und sind keine validierten Diagnose- oder Überwachungssysteme.

### Start

**Online:**

Das Spiel kann direkt über GitHub Pages geöffnet werden:

https://miaorwang.github.io/smart-farming-challenge/

**Lokal:**

1. `index.html` in einem aktuellen Browser öffnen.
2. Sprache (Deutsch/Englisch) auswählen.
3. Eines der drei Spiele starten und den Anweisungen auf dem Bildschirm folgen.

### Technik

- HTML, CSS und JavaScript; keine Datenbank erforderlich.
- Die bereitgestellte Fassung ist als eigenständige HTML-Datei ausgelegt.
- Für die Nutzung in Desktop- und mobilen Browsern konzipiert.

### Wissenschaftlicher Hinweis

Die Inhalte und dargestellten Daten sind für die interaktive Demonstration vereinfacht bzw. simuliert.

Spielentscheidungen oder -ergebnisse dürfen nicht als reale Tierwohlbewertung, Gesundheitsdiagnose oder validierte Sensorauswertung interpretiert werden.

## English

### About

Smart Farming Challenge is a bilingual collection of interactive educational games for science communication in livestock farming.

This release includes three topics:

- **Necktag© Detective** — dairy cattle
- **Moor Guardian** — water buffaloes
- **Hen Welfare Inspector** — laying hens

The interactive activities illustrate selected research-related questions. They are not validated diagnostic or monitoring systems.

### Getting Started

**Play online:**

Open the game directly through GitHub Pages:

https://miaorwang.github.io/smart-farming-challenge/

**Run locally:**

1. Open `index.html` in a modern web browser.
2. Select German or English.
3. Choose one of the three games and follow the on-screen instructions.

### Technical Notes

- Built with HTML, CSS and JavaScript; no database required.
- Designed as a standalone HTML file.
- Intended for desktop and mobile browsers.

### Scientific Disclaimer

The content and displayed data are simplified or simulated for interactive demonstration.

In-game decisions and results must not be interpreted as actual animal welfare assessments, health diagnoses or validated sensor analyses.

### Release Status

**Interactive Educational Demo · v6 — Mobile Optimized**

A demonstration release for teaching, exhibitions and science communication.

This designation does not imply completion of comprehensive technical, security or accessibility audits.
